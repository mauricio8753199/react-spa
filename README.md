# Necessário Para Rodar o Projeto  
Node: 18.12.1  
Npm: 8.19.2

# Comandos Utilizados    
Comando utilizado para a criação do projeto: npx create-react-app react-spa
Comando para instalar dependencias: npm install  
Comando para rodar o projeto: npm run start  

# Explicação Arquivos Gerados  
package.json: gerenciamento de dependências, versão, nome e comandos do projeto.  
O arquivo src/index.js renderiza o componente App.js que é o componente principal do sistema. O componente é renderizado dentro do HTML que está em public/index.html.  
Foi criado o componente Counter dentro da pasta src/Components. Esse componente recebe uma prop chamada "valor". Dentro de App.js é renderizado o componente Counter e através do hook useState é feito a atualização de estado do componente.
